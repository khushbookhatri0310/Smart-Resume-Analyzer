# Smart Resume Analyzer
An AI-powered Resume Analyzer built using Python and Streamlit.
## Features
- Upload Resume (PDF)
- ATS Score Calculation
- Skill Detection
- Missing Skills Identification
- Recommendations for Improvement
- Download ATS Report as PDF
## Tech Stack
- Python
- Streamlit
- pdfplumber
- ReportLab
- Pandas
## Project Structure
```
Smart-Resume-Analyzer/
│
├── app.py
├── parser.py
├── skills.py
├── ats.py
├── recommendation.py
├── report.py
├── requirements.txt
├── README.md
└── data/
```
## Installation
```bash
pip install -r requirements.txt
```
## Run
```bash
streamlit run app.py
```
